# Nafas requirements audit — SSMS schema review

> **Verification basis:** The project owner reports inspecting `NafasDB` in SSMS: 18 tables, 110 columns, Primary Keys and Unique Constraints verified, Foreign Keys verified and enabled/trusted, and indexes/CHECK constraints reviewed. No catalog export or detailed discrepancy list was supplied. Structural statuses below reflect that report and the 18-table documentation model; individual object definitions remain sourced from `database-data.js` until compared with an export. Statuses do not imply that application workflows or access rules are enforced.

## Status meanings

- **Complete:** The database structure reported/documented provides the required storage or constraint.
- **Partial:** The database structure supports the feature, but additional application/controlled-process enforcement is required or not verified.
- **Missing:** No suitable structure is documented.
- **Unverified:** The supplied SSMS summary does not confirm this object-level detail or behavior.
